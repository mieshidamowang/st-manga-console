# 漫画台 · 独立模块源码

本仓库公开本项目独立编写的模块，采用 MIT License。

**当前不是完整、可直接安装的 SillyTavern 扩展。请勿将仓库链接当作可用的插件安装链接。**

## 包含内容

- `director.js`：独立 OpenAI 兼容漫画编剧、上下文楼层选择、正文提取和结果保存。
- `character-library.js`：角色与服装库、别名匹配、Tag 注入、模型候选建档确认和 JSON 导入导出。
- `index.js`：SillyTavern / Tavern Helper 接入层，需另行提供适配的引擎和配置。
- `style.css`：独立模块界面样式。

## 未公开的依赖

原用户提供的预设尚未取得公开再授权，因此本仓库不包含原预设、其提示词、配套素材，以及从原脚本修改而来的生图引擎。

当前代码仍引用以下未包含文件：

- `comic-engine.js`（引擎和主界面）
- `director-preset.json`（提示词模块）
- `defaults.json`（引擎初始配置）

开发者需要自行编写兼容实现并提供合法授权的提示词后才能组装运行。本仓库不提供占位安装清单，不会假装成完整可安装插件。
