# 漫画台插件版0.1版本

独立扩展：先用任意酒馆预设写故事，再用单独配置的 OpenAI 兼容模型编写漫画分镜，最后调用 NovelAI 生图。无需将当前预设切成漫画台。

## 通过链接安装

在酒馆 **扩展 → 安装扩展** 粘贴：

```text
https://github.com/mieshidamowang/st-manga-console
```

安装后刷新，确保已安装并启用酒馆助手；数据库功能还需要原数据库插件。点击漫画台浮动按钮，分别在「编剧」和「连接」配置模型。已有 Git 安装可使用扩展更新；旧手动安装目录请先备份，再替换文件。不要同时运行另一个漫画台扩展或原内嵌漫画脚本。

这是本机完整漫画台 2.1 的正式发布包装，公开名称与版本为「漫画台插件版0.1版本 / 0.1.0」。保留原引擎、界面、98 条提示词及配套预设，替换先前独立精简实现。引擎内部版本仍为 2.1.0。

代码和内置素材一致不等于个人数据相同：不包含维护者的 Key、聊天、角色私有档案或浏览器图片缓存。首次安装需自行配置。此前精简版的 mangaConsoleOpen01 设置不会自动迁移。

## 使用

1. 酒馆保持自己的正文预设，例如「小金的云中梦工作室」。
2. 打开漫画台 → **编剧**：填写 API 基础地址、Key、模型 ID。可拉取模型列表，也可手填，不固定 Gemini 版本。
3. 地址应包含版本前缀，例如 https://你的服务/v1。Google 官方兼容地址为 https://generativelanguage.googleapis.com/v1beta/openai 。不填写原生 generateContent 地址。
4. 点“保存独立连接（含 Key）”可持久保存；未保存的 Key 只在当前页面会话中使用。
5. **预设** 标签保留色彩、页数、分镜、留白、语言、预填充、画风。高级编辑中可修改全部 98 条漫画提示词的内容和开关。固定页数可编辑「页数-每次N页」中的 N 值。
6. **连接** 标签配置 NovelAI，这是与编剧分开的生图接口。
7. 正文完成后先“预览发送内容”，再“正文转漫画并生图”。也可仅生成分镜，核对后从控制台生图。
8. 按需开启“正文完成后自动编剧并生图”；默认关闭，开启后会分别调用编剧和生图服务。

## 角色与服装（2.1 新增）

- 打开 **角色 / 服装**，手动新建、编辑、启停、删除角色和服装，可导入导出 JSON。
- 角色模板包括中英文名、别名、固定特征、五官正背面、SFW/NSFW 上下半身正背面、默认服装、负面 Tag；服装模板包括名称、别名、所属角色、上下半身正背面、负面 Tag。
- Tag 使用英文逗号分隔。所属角色填写角色中文名、英文名或别名；留空为通用服装。人物姓名和别名不要与其他人重叠。默认服装仅在当前镜头未指定服装时使用。
- 编剧收到启用的角色与服装库。每个人物提示词通过明确引用选择人物、视角、景别和衣服；已有分镜没有引用时也可按人物编号、提示词中的人名关键词匹配。Tag 在发送 NovelAI 前注入相应人物段，保留分镜动作，不注入整页背景。
- 开启“编剧发现主要角色 / 新服装时弹窗确认”（默认开启）后，模型在编剧或重绘时建议尚未入库的主要角色、明确出现的服装；弹窗允许编辑 Tag，再点“保存并使用”或“本次跳过”。主要角色判断来自独立编剧模型，并非每个名字必弹窗。仅写完小说而未启动漫画编剧时不会调用模型检测。
- 已存在名称不重复提醒；本次跳过不保存，之后重编仍可能建议。切换聊天或中止编剧会关闭待确认弹窗。未确认的候选不自动保存。
- 第一次使用：正文完成 → **编剧 → 仅生成 / 重编分镜** → 确认角色与服装 → **正文转漫画并生图**。一键“正文转漫画并生图”也会在需要时先建档，再继续出图。
- 旧的已保存分镜不会自动重新检测新角色；请点“仅生成 / 重编分镜”。角色库改动不会自动重画已有图片。
- 库保存于当前酒馆用户的 extensionSettings.mangaDirectorV2.library，跨聊天共用。没有复制智绘姬音频、角色参考照片或其加密导出格式；支持本插件 JSON 和含 characterPresets/outfitPresets 的明文对象。

## 上下文

- 最近 N 层包含目标层，每条用户/模型消息算一层。
- 指定范围从 0 开始，结束 -1 表示目标层，不得晚于目标层。
- 目标为最新非系统模型回复。即使范围不包含目标，目标正文仍单独发送。
- 优先提取 zw、content、game、plot、dream、正文；上传的小金预设已核对使用 zw。标签可编辑。
- 排除已配置的思考、状态栏、小剧场、选项等标签；没有正文标签则使用清理后的整层。
- 可附带角色卡、用户设定、数据库表格、绑定世界书的全部启用条目。世界书不模拟酒馆的关键字、概率、递归或向量触发器。
- 超过输入字符上限时报错，不静默截断。预览不调用模型。

## 漫画规则与工具传输

内置 director-preset.json 完整保留原 1111 的 98 条提示词及顺序，原禁用备份仍禁用。原色彩、页数、分镜、对白、语法、头尾引导、画风和 ToolCall 描述均保留。

setvar/getvar/roll、注释、角色名宏在单次编剧请求内解析，不修改聊天变量；额外第三方宏不会自动得到支持。

工具传输使用独立 OpenAI function tool 的 display_stream 字段，沿用原工具引导和说明；关闭后接收普通文本。原两个防截断脚本的全局 fetch 拦截器不挂入其他正文预设，独立请求直接封装和解包。提示词不能保证不拒绝，也不能突破服务端 token、权限或内容限制。

使用标准 model/messages/max_tokens/temperature/tools 参数，不写死模型专属 thinking 参数。服务商须支持相应接口；不支持 tools 时关闭工具传输，不能保证所有代理实现完全一致。

## 原文与设置保存

- 漫画模块和不含 Key 的配置：当前用户 extensionSettings.mangaDirectorV2。
- 编剧 Key：点击保存后写入当前用户文件 manga-director-connection.json，不进入模块导出。
- 分镜：当前聊天 metadata.mangaDirectorPlansV2，绑定原文和 swipe。
- 只在原文末尾追加插件图片区，不将分镜混入小说正文。
- 切换聊天、编辑正文或切换 swipe 会使旧结果失效。失败或取消保留旧分镜。重新编写分镜后，下次出图替换插件图片区。

## 保留功能

原 NovelAI 参数、轮询、并发、取消、单页重画、历史版本、画风导入导出、图片缓存/下载/预览、数据库模板导入与缝合、剧情推进资产、MOBI 导出代码继续保留。文字模型重写当前页使用独立编剧连接；参考图需要模型支持视觉。

仍依赖酒馆助手；数据库联动依赖原数据库插件，剧情推进调度仍由数据库插件执行。

## 安装与验证

将 st-manga-console 文件夹放入 SillyTavern/public/scripts/extensions/third-party/，刷新页面。更新前备份旧文件。包内 manga-companion.json 仅为可选兼容附件，本版不要求使用它。不要同时运行旧漫画台内嵌脚本。

已通过模拟 OpenAI/NovelAI 浏览器测试：正文转分镜、生图回填、原文保护、正文提取、预览、独立选项、模型列表、工具与普通返回、失败保留旧分镜、取消、缓存、重复请求、手机界面；另有楼层范围、嵌套宏、98条提示词保留、swipe失效测试。

没有使用真实 Key 执行收费请求。供应商跨域、真实模型质量、数据库联动和电子书阅读器显示仍需实测。API 为浏览器直连，不会自动修改酒馆服务器跨域设置。
